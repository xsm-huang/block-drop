### 实现中的问题与处理

- 路由依赖自动解析出 react-dom 19.3 与 React 19.2.3 冲突，以及超出 Expo 推荐范围的 Worklets。通过 expo install 显式选择推荐版本，未使用 force 或 legacy-peer-deps 绕过检查。
- 快速下滑采样保留过旧时间点，导致慢拖后突然快划被当作普通下移。调整采样窗口并补回归用例。
- React lint 检查阻止在渲染中更新手势引用。将触摸序列放到独立输入适配器，渲染仅装配实例。
- 保存失败原先可能让遮罩出现后游戏仍继续，已改为停止时钟并暂停；失败重试用例通过。
- 补充初始化代次检查，组件卸载后的旧异步读取不能恢复已失效状态。
- 音频插件默认开启后台播放，已明确关闭，配置输出不再添加媒体播放前台服务权限，也不申请录音权限。
- 开发客户端安装请求未获批准，没有安装 expo-dev-client，也没有重复请求。本轮提供普通 preview APK 配置，尚未运行云构建。

### 与初始设计的细化

- 首版模块采用较少的平级文件，职责仍按引擎、输入、控制器、存储与反馈分离，后续规模增大再拆目录。
- SQLite 使用一张 records 表，profile/game 两个键分别保存 JSON，结构版本使用 PRAGMA user_version；游戏状态与最高分仍在同一事务中提交。游戏 envelope 的 schema/rules 均为 1，rules 固定对应当前随机及旋转算法。
- 存档不保存绝对系统时刻，重力与锁定保存剩余时长；界面恢复统一暂停，避免补算离线时间。
- 消行动画首版采用短闪提示，尚未实现逐行淡出；不影响结算与保存的原子性。
- 保留原有 pnpm-lock.yaml，不让开发命令或 EAS 上传使用它；npm 锁文件为当前安装依据。
