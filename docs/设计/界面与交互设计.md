# 界面与交互设计

基线：[需求文档](../需求文档.md) · [设计总览](./设计总览.md)

## 1. 页面结构

首页与游戏页是两个路由；设置、覆盖存档确认、暂停和结算采用页内弹层，不各自增加导航页面。弹层出现时屏蔽棋盘输入。首页读档完成前不展示可能覆盖存档的开始按钮，使用简短加载状态。

### 首页线框

```text
┌──────────────────────────┐
│                    设置  │
│                          │
│        BLOCK DROP        │
│       轻松落下，慢慢玩    │
│                          │
│       最高分  12,800      │
│                          │
│       [ 继续游戏 ]       │
│       [ 新 游 戏 ]       │
│                          │
└──────────────────────────┘
```

无有效存档时，两个按钮合并为“开始游戏”。主操作位于屏幕中下部，设置入口具有至少 48×48dp 点击区域。有存档时选择新游戏，提示“开始新游戏将覆盖当前进度”，提供“取消”和“开始新游戏”。

### 游戏页线框

```text
┌──────────────────────────┐
│   得分 1,230  最高 12,800 │
│   ┌──────────────────┐   │
│   │                  │   │
│   │      当前方块    │   │
│   │                  │   │
│   │                  │   │
│   │      落点轮廓    │   │
│   │      已落地方块  │   │
│   └──────────────────┘   │
│ 点击旋转 · 滑动移动      │
│        [ 暂停 ]          │
└──────────────────────────┘
```

棋盘是主要触控区域，手指不需要按住活动方块，可在棋盘任意位置开始操作。暂停位于棋盘下方居中，便于左右手使用，触摸区域与棋盘不重叠。不增加方向键、下一块或暂存区域。

首次进入对局时展示一次简短教学卡：“点击旋转 / 左右滑动移动 / 下滑加速 / 快速下滑落底”，点击“开始”后启动计时。之后仅保留低干扰的简短底部提示；教学完成标记保存在本地。

## 2. 布局算法

- 尺寸单位使用逻辑 dp，时间使用 ms，速度使用 dp/s。
- 以安全区域内宽高为基础，横向边距初值 16，顶部计分区 64，底部提示与暂停区 88，区域间距各 12。
- 设可用棋盘宽为 W、扣除计分和底部区域后的可用高为 H，单格尺寸 `s = floor(min(W / 10, H / 20))`。
- 棋盘为 `10s × 20s`，保持正方形格子；宽屏时水平居中，不横向拉伸。
- 短屏先压缩装饰留白和辅助文案，保留计分、完整棋盘及至少 48dp 暂停点击高度；游戏页不使用滚动容器。
- 游戏过程中系统尺寸变化时重新布局，同时取消当前触摸，避免旧的距离累积误移。
- 大字号下计分区允许增加高度，并重新计算棋盘尺寸；较长数字缩减装饰文案，不覆盖棋盘。
- 真机至少验证约 360×640、360×800、412×915dp 三类窗口以及系统手势导航。

## 3. 视觉规范（初值）

| 语义 | 值 |
| --- | --- |
| 页面背景 | `#12161C` |
| 棋盘背景 | `#1B222C` |
| 弹层表面 | `#252E3A` |
| 主文字 / 次文字 | `#F1F5F9` / `#A8B5C5` |
| 主按钮 | `#93C5FD`，深色文字 |
| 弱网格 | `#293340`，1dp 以内 |
| I / O / T | `#67D5E8` / `#F1D879` / `#B9A0EA` |
| S / Z / J / L | `#8BD6A0` / `#EF939D` / `#8BAEF0` / `#EFB782` |

- 色块内部间隙初值 2dp，圆角 `min(3dp, s × 0.12)`；保持方块轮廓清楚。
- 实体方块使用实色；落点只画同色 1.5dp 轮廓，不用实体填充。与活动块重合时只显示实体，避免双边框。
- 分数 24sp、标题 28sp、正文 16sp、辅助文字 13sp；使用系统字体和适合数字展示的等宽数字形式。
- 不仅用颜色传递交互状态；按钮有文案，开关有文字与开闭状态，纪录提示有“新纪录”。
- 消行淡出初值 120ms，得分短促强调初值 150ms；动画不改变规则结算顺序，暂停时不继续驱动游戏。

## 4. 手势识别状态机

触摸序列状态为 `pending → horizontal / vertical / ignored → consumed`。点按只在 `pending` 状态正常抬手时成立。一次触摸不会由横移改成下移，也不会在滑动后旋转。

### 4.1 初始判定参数

| 参数 | 初值 | 用途 |
| --- | --- | --- |
| 点击最大持续时间 | 250ms | 长按不旋转 |
| 点击／方向启动容差 | 8dp | 容许手指抖动 |
| 方向主导比例 | 1.25 | `abs(dx) ≥ 1.25 × abs(dy)` 判为横向，反之向下判为纵向 |
| 移动一格距离 | 当前格尺寸 s | 横向与普通下滑换算 |
| 快速下滑最小位移 | `max(24dp, s)` | 短促抖动不触发落底 |
| 快速下滑速度 | 900dp/s | 最近 80ms 采样窗口的向下速度 |

以上为真机调试起点，不是验收时不可调整的硬编码常量。高速判定需同时满足位移、向下速度及纵向状态，不能只凭松手总距离判断。

### 4.2 事件处理顺序

1. 单指按下时记录坐标、时间、当前 `pieceId` 与对局 `sessionId`。
2. `pending` 超过容差后按主方向锁定；斜向尚未明显时继续等待，上滑主导则进入 `ignored`。
3. 横向累计有符号距离，每跨过一个 s 发出一次左／右命令，保留不足一格的余量，允许拖动中反向。
4. 触边后丢弃继续向边界外拖动的无效余量，避免反向时需要“偿还”大量距离。
5. 纵向每次采样先判断快速下滑；满足则立即发出一次落底并进入 `consumed`。此前实际普通下移的格数不改算。
6. 未满足快速条件时，累计向下距离并逐格发出普通下移。手指回移不产生上移，也不增加下次下移距离：回移后重设距离锚点。
7. 正常抬手时，若仍为 `pending` 且满足点按时长与位移条件，旋转一次；其他状态只结束触摸。

普通下滑期间继续遵守自动重力；每次成功手动下移后将重力剩余时间重置为完整间隔，避免刚拖完立即额外自动落一格。静止按住不冻结游戏，也不持续加速。

### 4.3 手势安全边界

- 每条操作命令校验 `sessionId` 与 `pieceId`；方块改变后旧手势立即消费，抬手再按才能操作下一块。
- 第二根手指加入、系统取消、后台、暂停、导航离开时取消当前触摸，不在取消时生成旋转或落底。
- 按钮和弹层事件不穿透到棋盘。局内任何时刻最多一个有效触摸序列。
- Android 屏幕边缘系统手势优先，不强制抢占系统导航触摸。

## 5. 弹层与反馈

| 场景 | 内容与行为 |
| --- | --- |
| 暂停 | “已暂停”；继续／返回首页，遮罩不可误触继续；系统返回保持暂停 |
| 后台恢复／恢复存档 | “继续上次游戏”；点击继续后才计时 |
| 结算 | 本局分数、最高分、必要时“新纪录”；再来一局／返回首页 |
| 设置 | 音效、震动独立开关；关闭按钮和系统返回均可退出 |
| 存档损坏 | “上次进度无法恢复，可以开始新游戏”；不阻塞正常开始 |
| 保存失败 | “进度保存失败，请重试”；保留内存对局，提供重试，不静默宣称已保存 |

旋转成功播放轻音；硬降或普通锁定播放一次落地反馈；消行播放消行反馈，可替代同帧落地反馈；失败旋转和普通逐格移动不播放。震动仅用于落地、消行、结束，避免密集触发。音效和震动默认开启为实施建议，后台停止播放，不申请录音权限。

## 6. 交互验收重点

覆盖需求 A03–A05、A11、A15–A16。用左右手分别测试慢拖、快速下划、斜划、短点击、长按、多指、边界反向、触底旋转、落底后不松手以及来电／切后台取消触摸。快速下滑测试需同时记录误触发与漏触发，不能只验证理想手势能成功。
